# CULT-ULHU character kits (wave 25)

20 playable entities, each with a Q / F / R ability kit, a right-click heavy
attack, a melee combo id, and a passive trait hook. Kits live in
`assets/characters/<id>/character.def`, generated by `generate_kits.py`
(do not hand-edit the defs — edit the KITS table and re-run).

## Power budget (enforced by tests_wave25)

| Slot | Role | Cooldown | Power |
|------|------|----------|-------|
| Q | bread-and-butter damage | 6–10 s | 80–150 |
| F | utility / CC / mobility / defense | 10–18 s | kind-dependent |
| R | game-changer | 40–60 s | ≤ 250 |
| RMB | heavy attack | — | mult 0.5–1.6, CC ≤ 2.5 s |

- Vitals: HP 400–700, move speed 4.5–7.0 m/s, stamina 100.
- Stamina: Q 20–30, F 25–40, R 45–65.
- CC: no single effect longer than 2.5 s; cooldowns are always much longer
  than the CC they apply, so nothing chains into a stunlock.
- Estimated kit DPS (Q damage/CD + R damage/CD, summons amortized at
  ~50 per spawn for Q/F and ~150 for R) must land in 10–40.
- Result: avatar-vs-avatar TTK around 15–25 s of focused combat — decisive,
  never a one-shot, never a grind.

## Effect vocabulary

`effect = <kind>` in a `[q]`/`[f]`/`[r]` section. `power` meaning by kind:

| kind | power means | range means |
|------|-------------|-------------|
| aoe_damage | damage in the area | radius (m) |
| projectile | damage on hit | max distance (m) |
| fear_aura | fear duration (s) | radius (m) |
| stun | stun duration (s) | target distance (m) |
| summon | number of spawns | spawn radius (m) |
| buff | duration (s) | radius, 0 = self |
| debuff | duration (s) | radius (m) |
| heal | HP restored | radius (m) |
| shield | HP absorbed | 0 = self |
| dash | meters moved | 0 = self |
| pull | drag meters toward caster | radius (m) |

Right-click kinds: `MeleeHeavy`, `MindControl`, `AcidSpit`, `EldritchGrasp`.
CC types: `Stun`, `Slow`, `Root`, `Fear`.

## Plugging in models

Each folder ships without a model file — the package loads as logic-only
and the engine uses the procedural placeholder. To give a character its
body, drop `model.fbx` (or `model.glb`) plus `rig.map` into its folder; the
loader picks it up with no code changes. Then run
`character validate <id>` in the driver and follow
`docs/bring_your_own_model.md` for the animation pass.
