## Codex implementation goals

1. Work **only** inside active `unreal 5.8`. Inspect the **local** tree (may be newer than GitHub), git status, and available asset files before any edit. Keep art research branch separate from code; never reset/force-pull/overwrite changes.
2. Acquire each selected source **only when a legitimate authorized downloadable package is offered** and the license permits the intended in-game use; do not scrape/steal viewer meshes, bypass logins, automate downloads against source terms, or assert rights that weren't checked. If login/purchase/permission needed, flag `BLOCKED_ACQUISITION` with exact URL and manual owner action.
3. Record every asset's origin URL, author, specific license, attribution requirements, source files / formats, rig and included clips, download status, and chosen character ID in a **machine-readable manifest**. Do not commit questionable model binaries or assets based on third-party IP.
4. Build an idempotent `unreal 5.8/Tools/ImportSelectedCharacterAssets.py` (or similarly named) using the **UE 5.8 Editor Python API**; implement asset import from local staged FBX/GLB/OBJ, static/skeletal recognition, preserve textures/materials, animations and skeleton associations. Use Blender batch conversion via script when necessary and installed; no invented commands.
5. In the **character selection UI**, existing `CultCharacterCardWidget.cpp` / `CultCharacterSelectWidget.cpp` are **currently text-only**. Add visible model thumbnails to cards, and ideally a rotating, lighted **real 3D preview** in the selected-character panel. Render thumbnails from authorized meshes (Blender or UE capture) and import into `/Game/CultUlhu/Characters/<id>/`. Missing asset gets a clearly marked placeholder **without breaking the grid**.
6. In actual gameplay, existing `CultUlhuPlayerPawn.cpp` is a scaled `ACharacter` with placeholder capsule and eye-glow. Attach the selected asset as `USkeletalMeshComponent` or `UStaticMeshComponent` with correct pose/pivot, bounds, materials, facing, and height. Keep the movement capsule authoritative, preserve camera, controls, menu, collision, and spawn safety. Do not render the placeholder eyes/capsule over a successfully loaded mesh. Crucially, **mesh coordinates and scale** need calibration: characters have canonical 20–30m heights and existing `SetActorScale3D(HeightM/1.8f)`; avoid double scaling.
7. Preserve and play any included animation: import skeleton + clips under the same asset folder; create minimal idle/walk/run/attack mappings if present. Ensure nonhumanoid rigs are not forced into Mixamo; use actual source skeleton and UE AnimBP/SingleNode as suitable. **Static mesh must still appear and be playable with no animation** (movement/capsule work, mesh stays in static pose); no freezing/crashing on missing clips.

9. Implement import retries, diagnostics/logging, and a simple re-run instruction. Do not modify old `unreal` projects. Keep binary downloads in local staging outside source control until legally confirmed and owner decides on Git LFS. Check file size and avoid GitHub's 100MB blob limit.
10. Compile `CultUlhuEditor Win64 Development` with `C:\Program Files\Epic Games\UE_5.8\Engine\Build\BatchFiles\Build.bat`, then run editor-side validation where possible. Show per-entity `IMPORTED_STATIC`, `IMPORTED_RIGGED`, `IMPORTED_ANIMATED`, `BLOCKED_ACQUISITION`, `BLOCKED_RIGHTS`, `BLOCKED_TECHNICAL`, `PENDING_SELECTION`. Never claim imported assets that are only linked.
