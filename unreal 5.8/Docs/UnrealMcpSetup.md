# Live Unreal MCP connection

Configured October 16, 2026 using Epic's plugins bundled with UE 5.8. No
third-party MCP binaries, packages, or external service accounts are required.

## Enabled in the canonical project

- ModelContextProtocol: Epic's native HTTP MCP server.
- EditorToolset: scene, assets, properties, viewport captures, logs, and PIE.
- AutomationTestToolset: discover, execute, and inspect automation tests.
- PythonScriptPlugin: supports the engine's Python-authored toolsets.
- ToolsetRegistry and EditorScriptingUtilities load through plugin dependencies.

Editor defaults in Config/DefaultEditorPerProjectUserSettings.ini enable server
auto-start, port 8000, path /mcp, and tool-search mode. Open the canonical
CultUlhu.uproject normally to start the editor and server. Existing per-user
editor preferences can override these defaults. If needed, run the editor
console command `ModelContextProtocol.StartServer`.

Codex's user-level configuration now contains an enabled streamable HTTP server
named `unreal-mcp` at `http://127.0.0.1:8000/mcp`. Restart Codex to load the newly
configured server into its native tool list. The current chat verified requests
using Tools/UnrealMcpProbe.py while its native tool list remained unchanged.

## Calling tools

Calls must be serialized because Unreal executes them on its game thread.
When a requested standard PIE session starts without a CultUlhu player pawn,
check for a stale Ctrl modifier before changing gameplay code. Epic's PIE
startup treats Ctrl as a request for spectator mode. Focusing the editor and
pressing/releasing Ctrl resolved this during the October 16 rendered check.
Coordinate desktop input with the owner; never interfere with another active game.
Discover with list_toolsets, read schemas with describe_toolset, then use
call_tool with toolset_name, tool_name, and arguments. Always confirm the loaded
project/map before edits; another Unreal editor on the same port could expose a
different project. Keep this unauthenticated editor endpoint local; no public
tunnel, firewall change, or remote exposure was configured.

The stdlib-only probe is also available with Unreal's bundled Python:

```
python "unreal 5.8/Tools/UnrealMcpProbe.py"
python "unreal 5.8/Tools/UnrealMcpProbe.py" --tool list_toolsets
```
