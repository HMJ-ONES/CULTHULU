# Next multiplayer work: simple Radmin flow

Requested by the owner on 2026-10-31, after the creep-wave fix.

Each mode should expose four clear entry options:

1. **Enter match**
2. **Enter / OK with hosting**
3. **Private room**
4. **Enter room code**

The priority is a very simple player experience over Radmin. This is a queued requirement, not a claim that competitive networking, room codes or matchmaking have been implemented. Existing Free Roam LAN/direct-IP co-op is the starting point. Competitive game state, troop simulation, damage and match results will need proper server ownership as that work proceeds.
